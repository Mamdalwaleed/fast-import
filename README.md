# 🚗 Fast Import

## 📌 Présentation

Fast Import est une application web moderne dédiée à l'importation et à la vente de véhicules.

Le projet permet de présenter des véhicules importés depuis l'Europe ainsi que des véhicules déjà disponibles en France.

L'objectif est de créer une plateforme professionnelle permettant aux clients de consulter les véhicules, demander une importation personnalisée et effectuer des demandes d'achat.

---

## ✨ Fonctionnalités prévues

### 👤 Utilisateur

- Consultation du catalogue des véhicules
- Recherche et filtres (marque, modèle, prix, année, kilométrage...)
- Affichage détaillé des véhicules
- Création d'un compte utilisateur
- Connexion sécurisée
- Ajout de véhicules en favoris
- Demande d'achat
- Demande d'importation personnalisée

### 🚘 Importation

- Formulaire de recherche de véhicule personnalisé
- Choix des critères :
  - Marque
  - Modèle
  - Budget
  - Année
  - Kilométrage
  - Motorisation
  - Options

### 🔐 Administration

- Gestion des véhicules
- Ajout/modification/suppression des annonces
- Gestion des demandes clients
- Gestion des utilisateurs
